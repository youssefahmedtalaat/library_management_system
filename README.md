# نظام إدارة المكتبة الذكي — Smart Library Management System (LMS)

منصة رقمية حديثة لإدارة المكتبات وتداول الكتب، متوافقة مع متطلبات التصميم وتجربة المستخدم المعتمدة على الذكاء الاصطناعي (AI Discovery)، ومبنية باستخدام **React 19** و **Vite**.

## 🚀 المميزات والتدفقات المكتملة

### 1. بوابة العضو (Member Flow)
- **فهرس البحث والتصفية المتقدم**: بحث فوري بالعنوان، المؤلف، رقم ISBN، أو الكلمات المفتاحية مع تصفية التصنيفات، التوفر، واللغات، وبيان موقع الرف بدقة.
- **بطاقة تفاصيل العنوان والنسخ المادية**: عرض بيانات الفهرسة الببليوغرافية مع جدول لجميع النسخ المادية وباركوداتها المنفصلة وحالاتها.
- **الحجز والانضمام لطابور الانتظار**: حجز العنوان إلكترونياً وحساب موقع العضو في الطابور بدقة.
- **لوحة متابعة إعاراتي**: متابعة تواريخ الاستحقاق والعد التنازلي للأيام المتبقية مع خدمة **التجديد الإلكتروني الذاتي (Renew)** وفق سياسات المكتبة.

### 2. بوابة أمين المكتبة (Staff / Circulation Flow)
- **لوحة المتابعة التشغيلية**: مؤشرات تفاعلية سريعة (KPIs) للإعارات النشطة، النسخ المادية، الحجوزات، والمتأخرات، ومحطة إعارة وإرجاع سريعة عبر الباركود.
- **مكتب التداول المركزي**: تسجيل إعارة جديدة مع فحص صلاحية وأهلية العضو وحدود الاستعارة المسموحة، وتسجيل استرجاع النسخ مع احتساب الغرامات اليومية آلياً عند التأخير.
- **إدارة الفهرس والنسخ**: نافذة إضافة العناوين وتوليد الباركودات المستقلة وتحديد موقع الرف.
- **إدارة الحجوزات والمتأخرات**: إدارة طوابير الحجز وإرسال إشعارات التوفر، وسجل الغرامات المالية مع إمكانية التحصيل والتسوية.

### 3. بوابة مدير النظام (Admin Flow)
- **إدارة الموظفين والصلاحيات**: إدارة حسابات أمناء المكتبة ومشرفي الفهرسة وإضافة حسابات جديدة.
- **سياسات التداول**: ضبط مدة الإعارة، أقصى عدد كتب، الحد الأقصى للتجديد، قيمة الغرامة اليومية، ومهلة الحجز بالساعات.
- **سجل التدقيق الرقابي (Audit Logs)**: توثيق زمني غير قابل للتعديل لجميع الحركات الحساسة.

### 4. أمين المكتبة الذكي (AI Librarian Discovery Drawer)
- درج جانبي تفاعلي (Slide-over drawer) مزود بشارات الذكاء الاصطناعي بلون **Warm Library Amber**.
- اقتراحات بحث جاهزة ذكية (مثل: *"قصة غموض قصيرة للمبتدئين"*، *"أفضل مراجع الذكاء الاصطناعي"*، *"سياسة تجديد الإعارة"*).
- استرجاع وشرح أسباب الترشيح وربطها المباشر ببطاقات الكتب بالفهرس وحالة توفر نسخها.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, Vite 8, Lucide React Icons.
- **Styling**: Vanilla CSS Variables (Tokens-based design system) مع دعم كامل لـ Dark Mode و RTL (العربية) و LTR (الإنجليزية).
- **Typography**: خطوط Google Fonts المعتمدة: **Cairo** للواجهة العربية و **Plus Jakarta Sans** للإنجليزية.
